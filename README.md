# Charly-Trading Mobile V1.0

PWA móvil de Charly-Trading basada en la versión web funcional.

- Modo: PAPER
- Datos: Tradier Sandbox (retraso aproximado de 15 minutos)
- Sin órdenes reales
- Interfaz adaptable a Android
- Manifest y Service Worker incluidos

La publicación móvil conserva el enfoque de validación PAPER antes de cualquier uso con datos/operación de producción.
